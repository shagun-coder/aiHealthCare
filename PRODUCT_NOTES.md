
# Vitals UI / Product Notes

## Visual language

- Near-black green/charcoal background.
- Ivory serif typography.
- Muted brass/gold accents.
- Sage green indicates stable/recovery signals.
- Thin astronomical rings and star-field motifs.
- Dense information is avoided on the watch face.

## Core user journey

1. Email/password authentication.
2. Daily vitals dashboard.
3. Personal baseline comparison.
4. AI Insight with tomorrow wellness prediction.
5. Trends over 7/30/90 days.
6. Device, security, notification and AI personalization settings.

## AI UX

The prediction card deliberately exposes:
- prediction score,
- model confidence,
- key factors,
- baseline comparison,
- on-device processing indicator.

Avoid presenting the prediction as a medical diagnosis or certainty.
